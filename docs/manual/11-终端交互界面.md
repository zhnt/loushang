# 第10章 终端交互界面

> 文档版本：V1.0.0

说明 TUI 启动、输入、命令、会话连续性、显示和退出操作。

本章以用户可执行操作为主，命令和路径均应在目标安装环境中再次核对。

## 10.1 TUI 启动方式

交互式终端中可通过 loushang --tui 或 loushang-tui 打开全屏工作界面。

### 功能要点
- stdin 和 stdout 都是 TTY 时进入 screen 交互面。
- 管道或重定向场景使用 plain prompt loop。
- --no-tui 可强制关闭全屏界面。

### 操作步骤
1. 确认终端支持交互和常见控制序列。
2. 启动 TUI 并观察初始状态。
3. 输入短消息验证渲染。
4. 使用 /quit 正常结束。

### 命令或配置示例
```text
loushang --tui
loushang-tui
loushang --no-tui -p "一次性任务"
```

### 验证方法
- 全屏模式能正确恢复终端状态。
- 退出后 shell 输入和光标行为正常。

### 注意事项
- 远程终端、复用器和不同 TERM 值可能影响显示。
- 异常退出后可使用终端 reset 命令恢复显示。

### 记录建议
- 建议在会话名称、工作日志或交付说明中记录“TUI 启动方式”的实际选择。
- 如实际结果与预期不同，应保留命令、状态码和最小复现信息。

## 10.2 输入与多轮对话

输入区支持编辑和提交消息，转录区持续展示用户、模型和工具事件。

### 功能要点
- 每轮输入应围绕当前目标补充新事实或调整方向。
- 长任务应在阶段边界总结状态。
- 工具运行期间的中断与后续输入需要遵守队列语义。

### 操作步骤
1. 输入明确目标和范围。
2. 观察模型是否需要工具或澄清。
3. 对不正确方向及时中断或引导。
4. 在完成前要求执行验证。

### 命令或配置示例
```text
请先只读分析，不要修改文件。
继续执行已确认方案，并运行相关测试。
```

### 验证方法
- 对话保持围绕同一任务上下文。
- 中断后不会继续未经确认的高影响动作。

### 注意事项
- 不要在输入区粘贴未经处理的秘密。
- 大量日志应保存为文件并提供精确路径。

### 记录建议
- 建议在会话名称、工作日志或交付说明中记录“输入与多轮对话”的实际选择。
- 如实际结果与预期不同，应保留命令、状态码和最小复现信息。

## 10.3 Slash Command

slash command 在本地控制会话、模型、工具和界面行为，不应被误当作普通模型提示。

### 功能要点
- 内置命令可通过 --list-commands 查询。
- 扩展、prompt 和 skill 也可能贡献命令。
- 命令来源和参数说明应在列表或补全中可见。

### 操作步骤
1. 运行 /help 等可用发现入口或外部 list-commands。
2. 输入完整命令和参数。
3. 检查本地结果是否符合预期。
4. 命令变更资源后使用 /reload。

### 命令或配置示例
```text
/session
/tools
/model
/export
/reload
```

### 验证方法
- 命令由本地路由处理，不进入模型正文。
- 未知命令产生明确提示。

### 注意事项
- 扩展命令可能执行代码，应确认来源。
- 排队中的 steer 或 follow-up 不应延迟执行扩展 slash command。

### 记录建议
- 建议在会话名称、工作日志或交付说明中记录“Slash Command”的实际选择。
- 如实际结果与预期不同，应保留命令、状态码和最小复现信息。

## 10.4 连续性选择器

交互式 --resume 和无参数 /resume 使用全屏可搜索选择器定位历史会话。

### 功能要点
- 空格可按需加载预览。
- 存在多个 Provider 时 Tab 切换 Domain。
- Ctrl+S 切换公共排序。

### 操作步骤
1. 打开 resume 选择器。
2. 搜索会话名称或项目。
3. 加载预览检查最后状态。
4. 确认并恢复目标会话。

### 命令或配置示例
```text
loushang --resume
/resume
```

### 验证方法
- 选择结果对应正确工作目录和任务。
- 取消选择不会改变当前会话。

### 注意事项
- 非交互环境不能依赖全屏选择器。
- 跨 Domain 恢复前应核对提供方和会话格式。

### 记录建议
- 建议在会话名称、工作日志或交付说明中记录“连续性选择器”的实际选择。
- 如实际结果与预期不同，应保留命令、状态码和最小复现信息。

## 10.5 模型与设置界面

/model、/scoped-models 和 /settings 用于查看或调整当前交互上下文的模型与设置。

### 功能要点
- 模型选择应展示规范键和来源。
- scoped models 用于理解不同范围的模型配置。
- 设置变更应区分会话级、项目级和用户级。

### 操作步骤
1. 打开 /model 查看当前选择。
2. 比较可用候选及其端点。
3. 完成选择并运行最小提示。
4. 用 /settings 检查持久化范围。

### 命令或配置示例
```text
/model
/scoped-models
/settings
```

### 验证方法
- 状态栏或会话信息显示正确模型。
- 重新启动后的持久化行为符合设置范围。

### 注意事项
- 模型切换可能改变成本、能力和数据处理边界。
- 不要在未验证时切换到名称相似的代理端点。

### 记录建议
- 建议在会话名称、工作日志或交付说明中记录“模型与设置界面”的实际选择。
- 如实际结果与预期不同，应保留命令、状态码和最小复现信息。

## 10.6 转录与复制

转录区用于查看稳定消息、流式草稿和工具事件，copy 命令可复制选定模型消息。

### 功能要点
- 流式草稿在结束后应转为稳定消息。
- 复制应针对明确消息，避免把整个敏感转录放入剪贴板。
- 终端选择与应用内复制可能具有不同语义。

### 操作步骤
1. 等待目标消息完成。
2. 使用 /copy 或界面复制入口。
3. 粘贴到安全位置核对内容。
4. 不再需要时清理系统剪贴板。

### 命令或配置示例
```text
/copy
/export
```

### 验证方法
- 复制内容与目标助手消息一致。
- 工具输出和隐藏元数据未被意外复制。

### 注意事项
- 剪贴板可能被其他应用读取。
- 远程终端的 clipboard 集成可能不可用。

### 记录建议
- 建议在会话名称、工作日志或交付说明中记录“转录与复制”的实际选择。
- 如实际结果与预期不同，应保留命令、状态码和最小复现信息。

## 10.7 退出与异常恢复

正常退出应保存必要会话状态并恢复终端；异常情况下可重新启动并使用 resume 继续。

### 功能要点
- /quit 是推荐的正常退出入口。
- 进程中断后应检查会话文件和工作树。
- 终端渲染异常与任务执行失败需要分别诊断。

### 操作步骤
1. 使用 /quit 正常结束。
2. 异常退出后运行 git status 和会话列表。
3. 恢复目标会话并总结最后完成事件。
4. 重新执行未获得结束证据的验证。

### 命令或配置示例
```text
/quit
loushang --list-sessions
loushang --continue
```

### 验证方法
- 终端恢复且会话可以再次读取。
- 没有把中断中的工具调用误报为成功。

### 注意事项
- 强制关闭可能留下不完整的外部命令副作用。
- 恢复后必须检查真实文件和进程状态。

### 记录建议
- 建议在会话名称、工作日志或交付说明中记录“退出与异常恢复”的实际选择。
- 如实际结果与预期不同，应保留命令、状态码和最小复现信息。
