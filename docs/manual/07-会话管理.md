# 第6章 会话管理

> 文档版本：V1.0.0

说明会话创建、保存、检索、恢复、分叉、压缩、导入和删除。

本章以用户可执行操作为主，命令和路径均应在目标安装环境中再次核对。

## 6.1 会话数据组成

会话是一次 coding 交互的持久记录，包含消息、工具事件、模型用量、诊断和分支上下文。

### 功能要点
- 会话记录服务于恢复和审计，不只是聊天历史。
- 工具输入输出可能包含文件片段和命令结果。
- 会话头部保存标识、名称、工作目录和关系信息。

### 操作步骤
1. 为任务创建清晰的会话名称。
2. 定期使用 /session 查看状态和统计。
3. 在重大阶段后导出或创建检查点。
4. 归档前审查是否包含敏感数据。

### 命令或配置示例
```text
/session
loushang --list-sessions
loushang --session-index
```

### 验证方法
- 会话事件顺序完整且可解析。
- 会话元数据与实际项目和任务相符。

### 注意事项
- 不要把会话文件当作无敏感信息的普通日志。
- 手工编辑 JSONL 可能破坏恢复和分支关系。

### 记录建议
- 建议在会话名称、工作日志或交付说明中记录“会话数据组成”的实际选择。
- 如实际结果与预期不同，应保留命令、状态码和最小复现信息。

## 6.2 列出与筛选会话

列表命令可按项目、名称、父会话、查询条件和诊断状态筛选持久记录。

### 功能要点
- 默认列表聚焦当前范围，--all-sessions 扩大搜索。
- JSON 格式适合索引、审计和自动化工具。
- session-limit 控制返回数量，避免扫描结果过大。

### 操作步骤
1. 先在当前项目运行默认列表。
2. 用名称或 query 缩小目标范围。
3. 需要时使用 all-sessions 跨目录查找。
4. 刷新索引后再次确认结果。

### 命令或配置示例
```text
loushang --list-sessions
loushang --list-sessions --list-sessions-format json
loushang --session-name-filter 登录 --list-sessions
loushang --session-has-diagnostics --list-sessions
```

### 验证方法
- 目标会话的标识、名称和工作目录一致。
- 过滤条件不会把不相关项目混入恢复候选。

### 注意事项
- 跨项目搜索结果必须再次核对工作目录。
- 大量会话环境应定期刷新索引并检查陈旧记录。

### 记录建议
- 建议在会话名称、工作日志或交付说明中记录“列出与筛选会话”的实际选择。
- 如实际结果与预期不同，应保留命令、状态码和最小复现信息。

## 6.3 恢复与继续

resume 和 continue 为不同使用场景提供显式或快捷恢复入口。

### 功能要点
- --continue 选择当前项目最近会话。
- --resume <id-or-path> 精确指定标识或文件路径。
- 交互式选择器支持搜索、预览、Domain 切换和排序。

### 操作步骤
1. 保存或提交当前工作树中的外部修改。
2. 查看候选会话的时间、名称和目录。
3. 恢复后先让系统概括未完成状态。
4. 比较当前代码与会话最后观察到的状态。

### 命令或配置示例
```text
loushang --continue
loushang --resume <session-id>
/resume <session-id-or-path>
```

### 验证方法
- 恢复后的下一轮能够引用之前的任务背景。
- 外部代码变化被重新读取，而不是依赖过期工具结果。

### 注意事项
- 恢复会话不等于恢复 Git 工作树。
- 长时间间隔后应重新运行测试和依赖检查。

### 记录建议
- 建议在会话名称、工作日志或交付说明中记录“恢复与继续”的实际选择。
- 如实际结果与预期不同，应保留命令、状态码和最小复现信息。

## 6.4 分叉与克隆

分叉用于从历史用户消息创建新的工作分支，克隆用于复制当前会话位置。

### 功能要点
- /fork 适合尝试不同解决路线并保留共同历史。
- /clone 复制当前会话状态，便于独立实验。
- /tree 用于查看和切换会话分支关系。

### 操作步骤
1. 确定需要分叉的历史决策点。
2. 创建分叉并使用可区分的名称。
3. 在各分支中记录不同假设和验证结果。
4. 通过 tree 检查父子关系并选择保留方案。

### 命令或配置示例
```text
/fork
/clone
/tree
loushang --fork <session-id>
```

### 验证方法
- 新分支保留预期历史，但后续事件相互独立。
- 分支关系能够在会话树中正确显示。

### 注意事项
- 会话分叉不会自动创建 Git 分支或工作树。
- 不同会话若写入同一工作目录仍可能互相影响。

### 记录建议
- 建议在会话名称、工作日志或交付说明中记录“分叉与克隆”的实际选择。
- 如实际结果与预期不同，应保留命令、状态码和最小复现信息。

## 6.5 上下文压缩

compact 用于在上下文增长时形成摘要，保留继续工作所需的关键信息。

### 功能要点
- 压缩目标是降低上下文占用，而不是删除持久会话历史。
- 摘要应保留目标、约束、决策、已改文件和验证状态。
- 压缩后仍需从真实文件重新读取关键事实。

### 操作步骤
1. 在阶段边界使用 /compact。
2. 检查摘要是否包含未完成事项和验收条件。
3. 补充遗漏的关键约束。
4. 继续前重新读取高风险文件和测试结果。

### 命令或配置示例
```text
/compact
python examples/coding/26_compaction_summary_evaluation.py
```

### 验证方法
- 压缩后的会话可以继续回答当前任务状态。
- 摘要不会把推断写成已经验证的事实。

### 注意事项
- 不要依赖压缩摘要保存精确代码或秘密。
- 关键批准和外部动作应保留独立审计记录。

### 记录建议
- 建议在会话名称、工作日志或交付说明中记录“上下文压缩”的实际选择。
- 如实际结果与预期不同，应保留命令、状态码和最小复现信息。

## 6.6 会话导入与导出

导入和导出用于迁移、归档、评审或继续已有会话。

### 功能要点
- HTML 导出适合人类阅读，JSONL 适合机器处理和再导入。
- /import 可导入 JSONL 并恢复为会话。
- 导出结果格式与导出文件格式是两个独立参数。

### 操作步骤
1. 确定导出用途和目标格式。
2. 选择安全的输出路径。
3. 导出后打开文件并检查完整性。
4. 共享前清理凭证、隐私和不必要的工具输出。

### 命令或配置示例
```text
loushang --export session.html
loushang --export session.jsonl --export-format jsonl
/import <session.jsonl>
```

### 验证方法
- HTML 可以独立打开，JSONL 每行可解析。
- 导入后会话标识和关系处理符合预期。

### 注意事项
- 导出文件可能包含源代码和本地路径。
- 不要导入来源不明或被篡改的会话文件。

### 记录建议
- 建议在会话名称、工作日志或交付说明中记录“会话导入与导出”的实际选择。
- 如实际结果与预期不同，应保留命令、状态码和最小复现信息。

## 6.7 会话删除

删除入口用于清理不再需要的历史会话，并通过确认步骤降低误操作风险。

### 功能要点
- /delete 打开历史会话选择器，不删除当前活跃会话。
- 删除前应判断是否需要导出、归档或满足保留策略。
- 自动化清理应有明确范围和可恢复机制。

### 操作步骤
1. 列出目标会话并核对名称、日期和目录。
2. 必要时先导出 HTML 或 JSONL。
3. 使用 /delete 选择历史会话。
4. 确认删除后刷新列表。

### 命令或配置示例
```text
/delete
loushang --list-sessions
```

### 验证方法
- 目标历史记录从列表中移除。
- 当前活跃会话和其他项目记录保持不变。

### 注意事项
- 删除可能不可恢复，应遵守组织的数据保留规则。
- 不要通过宽泛文件系统命令批量删除会话目录。

### 记录建议
- 建议在会话名称、工作日志或交付说明中记录“会话删除”的实际选择。
- 如实际结果与预期不同，应保留命令、状态码和最小复现信息。

## 6.8 会话目录与索引

session-dir、session-index 和 refresh-session-index 用于控制存储位置与查询效率。

### 功能要点
- 项目可把会话存储在 .loushang/sessions 或显式目录。
- 索引用于快速发现，不应替代原始会话文件。
- 目录迁移后需要刷新索引并检查路径。

### 操作步骤
1. 确定项目的会话存储策略。
2. 通过 --session-dir 显式指定需要的目录。
3. 运行 --refresh-session-index 重建索引。
4. 比较索引列表和原始文件数量。

### 命令或配置示例
```text
loushang --session-dir .loushang/sessions --list-sessions
loushang --refresh-session-index --list-sessions
```

### 验证方法
- 索引能够定位现存会话且无重复记录。
- 目录权限阻止无关用户读取敏感会话。

### 注意事项
- 备份策略应同时考虑会话文件和必要元数据。
- 网络文件系统上的并发写入需要额外验证。

### 记录建议
- 建议在会话名称、工作日志或交付说明中记录“会话目录与索引”的实际选择。
- 如实际结果与预期不同，应保留命令、状态码和最小复现信息。
