runtime factories, leases, composition and platform identity checks. The complete

implementation there. Application-owned Worker borrowing follows the separate
original create/unbound route. The two identical Worker owner lookup/type-check
methods share one implementation. Eight old method instances become seven actual
programs; underlying native factories and lease programs are reused, not counted
as new engines removed. Earlier A155 repair work is outside this delivery scope.

Coding keeps its three original nominal dataclasses, eight original fields,
constructors, physical slots, default lock and comparison flags. Plain empty-slot
implementation bases add no constructor, dictionary, lock, manager or state.

typed alias writes the original dataclass slot through ordinary attribute dispatch.
It neither duplicates the delivery flag nor bypasses subclass setters.

The complete application Selection remains Coding: storage/platform admission,

are borrowed original authority, not newly implemented by the factory adapter.
This delivery does not close the whole Selection class or C10.

## Failure, Retry And Ownership

Native factory creation remains outside the wrapper's try block. Only successful
release wrapping and `replace` mark outer delivery issued. On wrapping failure,
original binding disposal and selection close execute serially inside one try;
if the first fails the second is skipped, and the original error receives its
original fixed note. No aggregate cleanup or additional rollback is introduced.
The native factory's creation-issued state and the outer delivery-issued state
represent different events and remain separate original facts.

A release callback calls the original lease release before selection close.
Windows production checks still see `on_dispose.__self__.registry`, and the
construction probe still sees that wrapper's `release.__self__` original lease.
A selection-close failure leaves RuntimeBinding undisposed, preserving its
original retry route. Unbound disposal remains repeatable and does not set issued.
Application-owned borrowing never closes the application selection.

Nominal classes, constructor fields, public signatures and resolved hints stay
Coding. Private MRO, inherited implementation module/qualname, frames and globals
change. The old Code `replace` alias is no longer the execution hook; arbitrary
private module rebinding is not promised. Empty bases preserve layout, while
old inert value pickle lookup and normal lock-containing factory rejection are
bounded compatibility observations, not live owner pickle support.
