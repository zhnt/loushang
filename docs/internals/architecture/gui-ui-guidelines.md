# Loushang GUI 界面规范

本规范适用于桌面 GUI 和 Web 版共用的界面。修改前先找到对应章节和现有组件，在同类控件、状态和布局中复用已有做法。明确调整共用样式时，同步更新本规范，便于下次开发和评审对照。

## 视觉基线

界面以中性色和内容层级为主。用对齐、字重和留白区分信息，边框和阴影主要用来界定控件、浮层和少数需要独立阅读的内容。标题、正文、辅助信息应清楚可辨。文案只保留辨识、操作或判断状态所需的信息。

| 用途 | 使用方式 |
| --- | --- |
| 底色 | 页面和主要浮层用 `--paper`，侧栏用 `--sidebar`，次级表面用 `--panel`。同一对话区和输入栏外围保持同一底色 |
| 文字 | 正文用 `--ink`，次要操作用 `--ink-secondary` 或 `--muted`，提示和禁用项用更低的对比度。可用操作要一眼能辨认 |
| 边框与反馈 | 细边框用 `--line` 或 `--line-strong`，普通悬停用 `--control-hover`，侧栏悬停和选中分别用 `--navigation-hover` 和 `--navigation-selected` |
| 状态颜色 | 黄用于进行中或需要注意，绿用于成功或已连接，红用于失败、断开或危险操作。底色用对应的浅色 token，文字同时说明状态 |
| 字体 | 共用系统字体和中文回退。常规 UI 用 14 px，侧栏会话和紧凑控件用 13 px，辅助文字用 12 px。等宽字体适用于代码、路径和技术标识 |
| 图标 | 复用 `UiIcon` 的细线图标。同一层级的加号、图钉、关闭等次要动作保持相近的尺寸和视觉重量。图标按钮提供可访问名称 |

外观支持跟随系统、浅色和深色。控件、对话框、下拉菜单和自绘提示都跟随应用外观。全局颜色、字体和语义状态 token 统一维护在 [appearance.css](../../../gui/src/appearance.css)，控件样式和布局优先沿用 [App.css](../../../gui/src/App.css) 的同类规则。

## 框架与布局

- 桌面端保留顶部的前进、后退、菜单和窗口控制，并支持窗口缩放。拖动标题栏空白处可移动窗口，双击可最大化或还原。空白区域无需悬停说明。Web 端省去桌面标题栏，使用浏览器自身的窗口和导航能力。窗口功能参考 [DesktopFrame](../../../gui/src/DesktopFrame.tsx)。
- 侧栏的展开和折叠按钮放在侧栏顶部。折叠到约 48 px 时，窄栏仍保留顶部的展开按钮和底部的账户头像。
- 对话区标题用会话图标。文件夹图标用于项目或真实目录。顶部显示会话标题及必要的连接状态，Host 地址、工作空间路径和实例标识放到设置或工作面板。
- 环境、任务、子智能体和审阅共用右侧工作面板的标题、标签页和内容样式。宽度不足时，面板移到对话下方，避免挤压或盖住正文和输入框。底部面板入口沿用现有能力状态。
- 侧栏、对话记录和需要滚动的面板各有滚动区域。账户入口和输入框保持可见。缩窄窗口或打开侧栏、工作面板时，标题允许省略，按钮保持可操作，横向溢出留在对应内容内部。

## 侧栏与会话

- 置顶会话在上方。其余按项目和临时会话呈现，各处列表避免重复。会话可以没有项目，工作空间也可以没有关联目录。
- 项目和会话行使用一致的垂直节奏。会话标题使用常规字重、单行省略。组标题和项目名只做适度区分，选中用灰底表达。
- 加号和图钉等右侧次要动作在所在行悬停、键盘导航到该行或触屏可操作时显示。预留位置，显示时标题和图标的位置保持稳定。
- 能显示完整的会话标题省去悬停提示。标题截断时用应用内气泡展示全文，继承应用的表面色、字色和边框。持续显示的标题与 AppHost 保存的数据一致。
- 未命名草稿显示「新会话」。发送首条消息后，可以用截短的首句作临时标题，随后显示确认的摘要标题。重开界面时直接显示已经保存的标题。

实现参照 [ProjectNavigation](../../../gui/src/ProjectNavigation.tsx)。

## 对话与输入

- 阅读列默认最多约 760 px，窄窗使用可用宽度并留出边距。对话记录和输入框共享左右边界。滚动到底部时，最后一条回复与输入框之间留出空间。
- 用户消息靠右，用随文字长度收缩的浅层气泡。长消息在限定宽度内换行，保留用户换行。普通助手回复靠左，直接在对话底色上排版。代码块、工具结果和需要独立交互的内容各用对应容器。
- 输入栏的常用控件在同一水平线上。「＋」菜单从按钮上方展开，分为「添加」和「模式」。菜单项用细线图标配文字，分组标题使用辅助文字样式。「目标」归在「模式」组。发送和停止共用右侧位置。
- 「添加」用系统选择器选择当前电脑上的文件、图片或文件夹。待发送的附件统一用 64 × 64 像素的方形卡片，移除按钮在卡片右上角，鼠标悬停或键盘聚焦时出现，触屏始终可用。
- Enter 发送，Ctrl+Enter 换行。输入法选词期间由输入法处理 Enter。模型必选且尚未选择、输入为空或会话当前无法发送时，发送按钮置灰。
- 模型菜单先选模型，再展示该模型可选的推理档位。模型名后用小标签区分档位。没有明确档位时用「默认」表达，明确支持的「关闭」是单独档位。缺少可选档位时省去档位区域。当前模型未知时按界面实际状态提示选择或信息不可用。
- 模型菜单和设置下拉用主题表面、圆角、上下留白和清晰的当前项反馈。选项超出可用高度时才滚动，滚动留在列表内部。

实现参照 [MessageComposer](../../../gui/src/MessageComposer.tsx)、[ModelPicker](../../../gui/src/ModelPicker.tsx) 和 [SettingsSelect](../../../gui/src/SettingsSelect.tsx)。

## Markdown 阅读主题

应用外观决定整个软件的浅色或深色。Markdown 主题决定回答的排版与内容配色，同一个 Markdown 主题提供两种外观下的颜色。新增主题时每套主题用独立文件，在现有主题配置中注册，通过设置切换。

- 默认主题为 Loushang Minimal。正文和用户消息共用对话字体。标题通过字号、字重和段落间距区分，正文使用稳定的行高，引用用细竖线。
- 行内代码用浅层底色，多行代码沿用语言标签、语法高亮和复制按钮。保留原始缩进，长代码横向滚动。表格用适度的表头区分和细分隔线，宽表格独立横向滚动。
- 共用排版限定在 `.markdown-body`，主题变量限定在所属阅读主题范围。主题的配色与字号放在该主题文件。标题、段落、代码和表格的样式从渲染器输出的语义结构应用。

实现参照 [Markdown 排版](../../../gui/src/markdown/markdown.css)、[Loushang Minimal](../../../gui/src/markdown/themes/loushang-minimal.css) 和 [主题配置](../../../gui/src/markdown/preferences.ts)。

## 悬停、焦点与浮层

| 状态 | 使用方式 |
| --- | --- |
| 鼠标悬停 | 用克制的主题灰底提示可操作，避免改变尺寸、挪动文字或加高对比描边 |
| 鼠标点击与关闭弹窗 | 项目行和弹窗按钮沿用外壳的输入方式判断。右键菜单内的点击也进入同一判断。关闭弹窗后回到触发点时，鼠标操作保持干净的选中或悬停状态 |
| 键盘焦点 | Tab 到达可操作项时，有清晰的 `:focus-visible` 提示。菜单支持键盘移动和退出。焦点、悬停、展开和选中各自对应实际状态 |
| 关闭按钮 | 工作区和设置弹窗使用同一 `icon-close` 样式，28 px 控件、6 px 圆角、默认透明，悬停用主题灰底 |
| 菜单、提示和弹窗 | 继承应用主题，内边距和分组清楚，出现在滚动内容上方。侧栏滚动条不会盖住菜单或对话框。长内容用面板内部滚动 |
| 悬停提示 | 用 `data-tooltip` 接入全局提示层，颜色跟随应用外观。提示留在窗口内，支持鼠标悬停和键盘焦点。控件的可访问名称用原有标签提供 |
| 禁用和危险动作 | 未实现或当前不可用的入口置灰并阻止操作。停止 Host、删除等实际危险操作用红色和对应的确认流程 |

实现参照 [ContextMenu](../../../gui/src/ContextMenu.tsx)、[TooltipLayer](../../../gui/src/TooltipLayer.tsx)、[WorkspaceEditor](../../../gui/src/WorkspaceEditor.tsx) 和 [SettingsDialog](../../../gui/src/SettingsDialog.tsx)。

## 连接、设置与账户

顶栏使用同一个状态标签，未打开会话也可见。连接、重启或等待会话同步时为黄色「连接中」。收到 AppHost 的有效连接确认后为绿色「已连接」。连接失败或丢失时为红色「已断开」。说明和诊断详情放在对应的界面，连接中的提示直接复用顶栏标签。

本地 AppHost 未运行且可以启动时，空会话在对话区中央显示状态和「启动并连接」主按钮。已有对话时，把同一个操作放在输入框附近，保留消息的阅读空间。

设置采用左侧分类、右侧内容布局。常规包含界面语言、应用外观和 Markdown 主题。Host 页集中显示连接管理和 Host 信息，字段、状态和操作区分清楚。各页共用窗口高度，超出部分在内容区滚动。账户从侧栏底部打开，菜单显示账户摘要和设置入口；账户类型与可复制 ID 放在账户详情。

UI 文案用语义化翻译键，简体中文和英文一起维护。统一使用「会话」「工作区」「目标」「任务」「环境」「审阅」。用户名、对话内容、模型 ID、路径和原始诊断保持其原值。资源位于 [本地化目录](../../../gui/src/i18n/locales/)。

## 开发自查

1. 对照同一场景的现有控件、样式变量和本规范，确认新增视觉状态有明确含义。
2. 按改动检查浅色和深色，涉及浮层或主题时至少验证一次应用外观与系统外观相反的情况。
3. 涉及弹窗、菜单或侧栏时，分别走一遍鼠标和键盘路径。重点看右键打开、悬停关闭、鼠标关闭后焦点回到项目行，以及 Tab 焦点。
4. 涉及布局时检查普通与窄窗口、长中文和英文标题、侧栏折叠以及工作面板打开。遇到系统焦点或滚动条问题时，在受影响的原生平台补一次验证。
5. 根据改动范围跑最相关的检查。[浏览器布局回放](../../../gui/README.md#browser-layout-playback)已有工作区弹窗、右键菜单、字体和 Markdown 主题场景，可按用例筛选。
