## 评审方式与范围

三个 xhigh agent 从独立上下文检查固定提交、候选设计、调用方及测试源码；不把实现者自查或其他 agent 报告当作独立证据。职责与复用由 `budget_ownership` 负责，运行与失败由 `budget_runtime` 负责，数据与兼容由 `budget_data` 负责。三份初审均为静态取证；实现者随后复现问题、修正并执行离线回归。首次评审结论不追溯改写为修复版通过。

重点是预算权威、复用边界、两次确认、宿主入口、暂停恢复、模型输入与冷读。没有改变部署结构或公共协议，因此不开展部署矩阵；不据离线适配器证明真实模型效果、计费或 token 硬上限。
