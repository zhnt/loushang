# Legacy Documents

## Status

Legacy / historical.

This directory preserves older boundary protocols and design notes that are
still useful for context. They are not current implementation
contracts.

## Reading Rule

- Use these documents for background, vocabulary history, and long-term product
  intent.
- Do not treat older subsystem names such as `loushang-methods` as current package
  names.
- Do not treat `loushang-channel` notes here as evidence that a current
  `src/loushang/channel/` implementation exists.
- When these notes conflict with current docs, prefer accepted ARDs, live
  architecture docs, code, and tests.
